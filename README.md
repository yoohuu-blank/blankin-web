# BLANK 홈페이지 (blankin.net)

GitHub Pages로 배포되는 블랭크 홈페이지입니다.

## 포트폴리오 글 올리기·고치기
구글 시트 '공개용' 탭에서 한 줄을 추가하거나 고치면 몇 분 안에 사이트에 반영됩니다.
'공개' 칸이 비어 있거나 X면 사이트에 보이지 않습니다.

## 사진 올리기
1. 이 저장소의 `photos` 폴더로 들어갑니다.
2. 오른쪽 위 **Add file → Upload files**를 누르고 사진을 끌어다 놓습니다.
   파일 이름은 영어·숫자로 짓습니다. (예: `2026-asan-01.jpg`)
3. 아래 **Commit changes**를 누릅니다. 1~2분 뒤 사이트에 올라갑니다.
4. 사진 주소는 `https://blankin.net/photos/파일이름.jpg` 입니다.
   이 주소를 시트의 '대표이미지' 칸이나 본문에 넣습니다.
   본문에 넣을 때: `![사진 설명](https://blankin.net/photos/파일이름.jpg)`

사진은 가로 2000px 이하, 한 장에 1MB 이하로 줄여서 올리면 사이트가 빨라집니다.
